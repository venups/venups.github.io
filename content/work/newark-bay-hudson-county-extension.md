## The project

The Newark Bay–Hudson County Extension program includes the Newark Bay Bridge Replacement. The work combines model-based delivery with construction-stage analysis of steel I-girder bridges, on a scale where consistency between engineers matters as much as any single calculation.

## My role

- Served as BIM lead, organizing Bentley Blueprint sessions and a shared page and channel of OpenBridge Modeler training documents and recorded videos.
- Led the construction-stage finite element discussions: staged deflection, common-bay cross-frame installation, architectural camber, haunches, longitudinal live-load force and steel I-girder staging.
- Set up the Bluebeam drawing-review procedures so reviews run the same way across the bridge team.
- Mentored junior engineers, and gave them ownership of templates and specialized calculations.

## The tool it produced

Rebuilding each bridge in CSiBridge from the OpenBridge model would have repeated the same expert work ten times. That is the problem [Steel Bridge Pal](/work/steel-bridge-pal) solves, saving an estimated 200 hours per model.
