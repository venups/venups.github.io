# Images

Put pictures here, in a folder named after the page that uses them:

    public/images/work/us-20-fox-river/cover.jpg
    public/images/work/us-20-fox-river/erection-stage-3.jpg
    public/images/stories/...
    public/images/writing/local-ai-field-notes/benchmark.png
